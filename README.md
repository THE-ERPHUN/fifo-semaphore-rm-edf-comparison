# fifo-semaphore-rm-edf-comparison
Research paper and Python simulation comparing FIFO, Rate Monotonic (RM), and Earliest Deadline First (EDF) scheduling algorithms with semaphore-based resource synchronization.
# Real-Time Task Scheduling and Semaphore Analysis

## Overview

This repository contains a research paper and a Python simulation for analyzing and comparing three CPU scheduling algorithms: First-In, First-Out (FIFO), Rate Monotonic (RM), and Earliest Deadline First (EDF).

The project investigates scheduling performance in periodic real-time task systems and examines semaphore-based synchronization when tasks compete for a shared resource.

## Repository Contents

- **Research Paper:** Detailed discussion of the scheduling algorithms, simulation methodology, performance metrics, experimental results, and limitations.
- **Python Implementation:** Simulation code used to compare FIFO, RM, and EDF under the defined task-set and semaphore assumptions.
- **Experimental Results:** Numerical results and supporting data generated by the simulation, where included.

## Scheduling Algorithms

### FIFO — First-In, First-Out

A non-preemptive scheduling policy that executes ready jobs in arrival order.

### RM — Rate Monotonic

A fixed-priority preemptive scheduling algorithm in which tasks with shorter periods receive higher priority.

### EDF — Earliest Deadline First

A dynamic-priority preemptive scheduling algorithm that prioritizes the ready job with the earliest absolute deadline.

## Semaphore-Based Synchronization

The simulation models a binary semaphore to control access to a shared resource. It considers critical sections, resource contention, and blocking while waiting for semaphore access.

## Evaluation Metrics

The algorithms are compared using:

- Average waiting time
- Average turnaround time
- Average resource waiting time
- Average blocking time
- Number of deadline misses

## How to Run the Simulation

Requirements: Python 3.

Run the simulation from the project directory:

```bash
python fifo_semaphore_comparison.py
```

Consult the source code for the exact simulation assumptions and generated output files.

## Research Scope and Limitations

The results are specific to the task sets, scheduling rules, critical-section lengths, and semaphore behavior implemented in the simulation. They should not be interpreted as universal rankings of the scheduling algorithms.

Before using the numerical results in further research, validate the implementation and its metric calculations.
